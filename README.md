
# THE PAIN TDL - CYBER GLITCH EDITION

Version 1.0.0

A Python-based WhatsApp support request preparation tool.

## Features

- THE PAIN BAN TOOL
- THE PAIN UNBAN TOOL
- HELP
- ABOUT
- EXIT
- Gmail SMTP support (manual confirmation)
- Official WhatsApp contact form

## Requirements

- Android
- Termux
- Python 3
- Git

## Installation

    pkg update -y && pkg upgrade -y
    pkg install python git -y

    git clone https://github.com/TONPSEUDO/THE-PAIN-TDL-BAN

    cd THE-PAIN-TDL-BAN

    bash start.sh

## Gmail

Gmail configuration is stored locally in .env.

Never upload Gmail credentials to GitHub.
