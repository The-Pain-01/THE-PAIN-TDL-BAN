# THE PAIN TDL BAN

Outil de signalement massif d'un compte WhatsApp via emails à support@support.whatsapp.com.

## Installation

    pkg install python git -y
    python3 -m pip install requests
    git clone https://github.com/TONPSEUDO/THE-PAIN-TDL-BAN
    cd THE-PAIN-TDL-BAN
    nano config.txt   # mets tes comptes Gmail + App Password
    bash start.sh

## Config

Dans `config.txt` : une ligne par compte, format :

    email@gmail.com:motdepasse_app

Voir le guide : activer 2FA puis générer un App Password Gmail.
